## 一、桌面端生理信号分析软件

**技术栈：** PyQt5、SQLite、Python、Matplotlib、Qt Designer、neurokit2、MNE

实验室用的科研软件要收费，我就打算用开源技术自己写一个桌面程序，先自用，以后也许商用。

导入信号文件后，程序解析出信号。界面上可以选各种滤波、R 峰检测等自研和开源算法，设置窗口和步长，然后展示心率图、近百个 HRV 指标、庞加莱图，覆盖时域、频域和非线性分析。

已申请软著《基于心电图与光体积描记法图的桌面端生理信号分析软件》（2024）。

## 二、应激生理监测系统

这个系统包括腕表硬件、算法、手机 App、云服务器后端和 Web 端，用来监测、分析、预警人员的应激水平。我负责整体架构，以及云端后端、App、Web 端这些软件部分的开发；算法和硬件由队友负责。

### 2.1 云端后端

**技术栈：** Java、Python、Spring Boot、MySQL、MyBatis-Plus、Shiro、HikariCP、JWT

后端负责存储生理信号和用户数据，用算法计算各项指标，并和 Web 端、App 端通信。

1. 用 Shiro 实现 JWT 持久化登录、认证和授权。
2. 用 MySQL 存用户表和数据。
3. 用 MyBatis-Plus 操作数据库，HikariCP 做连接池。
4. Python 信号算法模块和 Spring Boot 解耦。当时网上没有完整方案，我单独写了一篇经验贴。

已申请软著《基于用户管理的多通道生理信号分析云端软件》（2024）。

### 2.2 Web 前端

**技术栈：** Vue3、JavaScript、Element Plus、Axios、ECharts、Vuex、Vue Router

连接上面的后端。用户登录后可以管理自己的云端数据：上传新的信号文件、删除、对已上传的信号做进一步分析、查看波形和 HRV 结果。

1. 用 Vue3 构建，路由和状态管理用 Vue Router 和 Vuex，状态持久化用 vuex-persistedstate。
2. UI 用 Element Plus。
3. 用 ECharts 画百万数据点的折线图，延迟控制在 3 秒内。

已申请软著《基于用户管理的多通道生理信号分析网页前端软件》（2024）。

### 2.3 手机 App

**技术栈：** uni-app、Vue2、uView2

App 通过蓝牙连接腕表和服务器，控制腕表采集信号、上传到服务器分析，再取回并显示结果。

## 三、小型开发任务

### 3.1 应激分析系统

根据采集到的生理信号快速判断是否应激，算法由组内自研，界面和项目一一样用 PyQt5。

### 3.2 HRV 分析报告网页

给实验室的客户做的。以前客户每次采集完都要把数据交给我们，分析出报告再返回。现在客户在网页上传信号文件，后端分析计算后直接生成 PDF 报告返回。
