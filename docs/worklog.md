## 决定

- 2026-10-29 第一版：深色单页，被车主否掉，原因是「像简历」「字太多」「AI 味重」。
- 2026-10-29 第二版：参考 antfu.me、simonwillison.net、swyx.io 等，改成多页编辑风；首页只放一句话和作品卡。
- 2026-10-29 第三版（车主反馈后）：
  - 学历改为西电本硕（本科电子信息工程，硕士电子信息）。
  - 车主在流程里只做两头：提创意、审方案；手动发版。中间分诊、开发、评审、合并都是 AI（Cursor 自动合并）。
  - 主案例换成「玩家反馈 → 合入」的真实记录 #2593，不写「自动上线」，因为发版是手动的。
  - 不写「已盈利」：10 月交易 110 元、全年 185 元，撑不住。改写「AI 生文、生图单项毛利 78% 以上」。
  - 「半年增长 1000%」没有出处，先不写，等车主给后台截图。
  - 文案去掉口号和「方法论」段落，只写带日期、编号、数字的事实。
  - 数据库截图含密码哈希和手机号，不用。

- 2026-10-29 第四版（车主要求自查一轮质感）：
  - 首页标题改成「一个人，带一支 AI 研发团队。」，数字挪到标题下方的数据条。
  - 全站改成左标题、右内容的分栏（`Section` 组件），参考 Anthropic 官网。
  - 反馈修复流程改成可点击：每一步点开看真实记录（Issue 原文、认领评论、代码 diff、评审、CI、合并、发版公告）。
  - 分工图去掉黑色块；发版写成「工作日晚上统一发版」（车主提供）。
  - 学校、公司加官网链接；外企德科官网不确定，没加。
  - 晨曦酒馆用自媒体仓库里的封面、角色设定图、关键帧和分镜表重做。
  - 新增 `AGENTS.md` 规则文档；PR 构建检查通过后可自动合并（车主同意）。

- 2026-10-29 第五版（车主反馈后）：
  - 去掉「大功能也一样」这种读不懂的标题，改成「大功能：一下午拆成 6 个 PR」。
  - 「PR 越来越多」改成「产能：每天 18 个 PR」；「我在里面做什么」改成「一条全自动的流水线」，每一步标出是哪个 AI，首页数据条加「8 个 AI 定时任务轮班」。
  - 用户、玩家反馈、内容和成本三类运营数据并进一栏，分页看（方向键可切换）。玩家反馈的数字是新加的。
  - 三个案例页加吸顶目录，滚动时高亮当前一节。
  - 信号平台：去掉「3 秒内画出百万个数据点」（听着慢）；顶部数字改成 4 端、3 项软著、近百项指标、一键出报告；补上 App 截图和两页 PDF 报告；证书占位框去掉，改成文字列表。
  - #1 里的图片之前下载不了（云端代理挡了 github.com 附件地址），这次通过跳转后的直链拿到了。

- 2026-10-29 交互和真实数据（#3）：
  - 热力图点某一天，看那天新功能、修复、文档等各合入几个；方向键切换日期。几个有案例的日子（反馈修复、约团排期、两道门禁上线）标了白点，点开有 PR 编号和案例链接。
  - 车主定：小程序仓库是私有的，网站不放每条 PR 的标题，只放按类型的数量，外加少量案例的编号。
  - 每月柱状图拆成新功能、修复、其他三段，悬停或聚焦看数。
  - 活跃用户曲线支持方向键和手机拖动。
  - 数据条（首页、小程序页顶部）悬停或聚焦显示来源和日期。
  - 「AI 犯过的错」四张卡能点开，看这道检查哪天、哪个 PR、为什么加的。顺手改了两处不准的说法：译名检查查的是同一个英文名有没有两种译法，不是和社区译名比对；体积检查管的是每个分包，不只主包。
  - 约团排期时间线每一步附上 PR 编号和原始标题。
  - 晨曦酒馆的五道关改成可点击，每关看交出什么、我做什么。
  - 截图都能点开看大图，同一页的图可以左右翻。
  - PR 编号不做成链接，因为外人打不开私有仓库。

- 2026-10-30 改版（#4，车主要「顶级水准、要炫技」，参考谷歌 Antigravity 和顶级个人站）：
  - 首页开场换成 Canvas 粒子场：1,318 个点各代表一个合入的 PR，会躲鼠标；往下滚，点按合入日期飞成每日柱状图，悬停或方向键看每天的类型拆分，有案例的日子附链接。原来首页的热力图并进这里，小程序页的热力图保留。
  - 标题逐字升起；数据条进入视野时数字从 0 数上去。
  - 作品区按分量重排：小程序、信号平台各占整行大卡，晨曦酒馆和「最近在做」是半行小卡。卡片有跟随鼠标的柔光，小程序的手机截图会随鼠标微转。
  - 信号平台：车主说是西电 × 第四军医大联合的保密项目，首页和项目页都标「保密项目，只展示公开部分」，不多写细节。首页配一段合成心电动画，实时找 R 峰算心率，标明是示意。
  - 晨曦酒馆：写上车主定的目标「国内最大的 D&D 跑团自媒体，新闻、科普、教学、短剧都做」；封面改用角色设定图。
  - 去掉信号平台 Web 端的文件列表截图（只是一张表格，不好看）。
  - 全站加一层很淡的纸张颗粒。
