# 演讲 03「工具准备」：企业要准备哪几类工具

查询日 2026-11-17。价格、额度以当天打开的官网为准，不含税，活动价会变。

查不到的数字不写。这份文档不改演讲页，给 [HAN-1823](https://linear.app/hanglen/issue/HAN-1823) 用。

车主实际在用什么，对照的是小程序仓库 `dev`（2026-11-17 读取）：`AGENTS.md`、`docs/automation-routines.md`、`docs/routines/README.md`、`docs/routines/feedback.md`、`docs/workflows.md`、`docs/cost-ledger.md`。

## 结论

做定制软件并持续改，先备四样：写代码的 AI、放代码的地方、管任务的地方、让代码跑起来的地方。

工作流拆成两截。公司里收反馈，一张飞书表就够。

检查、部署、失败留痕，用 GitHub 自带的 Actions，不必再买扣子或 Zapier。

建议这一页放 5 类。现在的「收反馈」并进「工作流」，空出来的一格给「放上线」。

模型接口、知识库、监控、沟通软件先不上这一页，理由在最后一节。

## 建议上页的版本

每格最多两个名字。入门和进阶相同的，是因为换平台比换名字贵。

| 类型 | 入门 | 进阶 |
|---|---|---|
| 写代码的 AI | WorkBuddy、Trae | Claude Code、Codex |
| 放代码 | GitHub | GitHub |
| 管任务 | GitHub Issues | Linear |
| 工作流 | 飞书表格 | GitHub Actions |
| 放上线 | 微信云开发 | 微信云开发 |

前三行和现在的表一样，可以照旧。第四行不要再写「自动转成任务单」：那是做法，不是一个要买的产品。

第五行是新的。做微信小程序，入门和进阶都是微信云开发；做普通网站再换托管，这一页先不展开。

讲者备注里补一句就够：飞书表里的新反馈，由写代码的 AI 定时读走、开成任务单。车主现在就是这么转的，不是飞书自动化自己开单。

「用在哪」只分两环：做出来、维护。「亲身」只标上面那些文件里写明在用的。

### 写代码的 AI

WorkBuddy 体验版免费，每月 500 积分。标准版 99 元/月，连续包月 70 元/月，连续包年 672 元。

和 CodeBuddy 同一账号，积分共享。[定价](https://www.workbuddy.cn/docs/workbuddy/Pricing)

Trae 国内版（trae.cn）免费用户每月登录送 500 积分，另有注册和签到。会员 Lite 单月 49 元，连续包月 45 元（新用户首月 39 元），每月 2,000 积分。

Pro 单月 99 元。支付是支付宝、微信、抖音，文档更新时间 2026-11-17 09:51。[套餐](https://docs.trae.cn/ide_plans-and-billing)

Claude Code 含在 Claude 付费档，和聊天共用额度。Pro 月付 20 美元，年付一次 200 美元（折合 17 美元/月）。

Max 100 美元/月，Ultra 200 美元/月。免费档不含 Claude Code；定价页写信用卡，没写中国区付款方式。[定价](https://claude.com/pricing)

Codex 含在 ChatGPT 套餐里。产品页标 Plus 20 美元/月、Pro 100 美元/月，Business 年付 20 美元/席起。[产品页](https://openai.com/codex/)

仓库里写明的分工：Claude 做前端和分诊，Codex 做后端和美术，Trae 做后端。WorkBuddy 是入门选项，这几份文档没写在用。

### 放代码

GitHub 免费版 0 美元，公开库和私有库数量都不限。Team 4 美元/人/月。

私有库的 Actions：免费版 2,000 分钟/月，Team 3,000 分钟/月；公开库的分钟不计入。Issues 含在免费版里。[定价](https://github.com/pricing)

车主的小程序仓库是私有的，分支、PR、检查都在 GitHub。这一页入门和进阶都写 GitHub，做完再搬一次不划算。

### 管任务

GitHub Issues 含在上面的免费版里，适合单少的时候。

Linear 免费版 0 美元：人数不限，2 个团队，250 张单，单文件上传 10MB。Basic 按年付 10 美元/人/月，单不限、5 个团队。

Business 按年付 16 美元/人/月。定价页的卡片是年付价，月付没标在卡片上。[定价](https://linear.app/pricing)

车主 2026-11-05 起任务只开在 Linear。免费版按没归档的单计额度，满了先归档关掉超过 7 天的单再开新单，这是仓库里的操作约定，定价页没写归档算不算进 250。

### 收反馈和工作流

飞书套件免费版含即时消息、云文档、多维表格、知识库，支持 100 用户。商业标准版 50 元/人/月，专业版 80，旗舰版 120。

页面注明所有版本按年付费。[版本对比](https://www.feishu.cn/pricing)

套件里的多维表格，自动化和工作流共用次数：免费和标准各 200 次/月，专业 5,000 次/月，旗舰和企业版 50 万次/月。触发成功才计一次，次月 1 日重计。[帮助中心](https://www.feishu.cn/hc/zh-CN/articles/949255360693)

另外有一套单独卖的飞书多维表格，别和套件价混用。基础版免费、20 个账号；专业版 35 元/人/月，旗舰版定价页只留了电话。

自动化次数：基础版 200 次/月，专业版 5 万次/月，旗舰版 50 万次/月。[独立版定价](https://base.feishu.cn/pricing)、[次数说明](https://base.feishu.cn/helpcenter/ai8y3d44/tys0fnxv?_lang=zh)

车主的玩家反馈进飞书表「DND 小程序用户反馈」。定时任务只处理状态是「新反馈」的行，在 Linear 开单，再把状态回写成「已转 Issue」。

转单的是 AI 定时任务，不是飞书自动化。所以进阶格写 GitHub Actions，不写「再买一个自动化」。

GitHub Actions 车主在用的包括：每个 PR 的门禁、云函数合入后自动部署、任一工作流失败就留痕。分钟额度见上面 GitHub 一节。

定时领单不在 Actions 里。车主在 Claude、Codex、Trae 各自的定时里贴一句「读仓库里的提示词」。

### 放上线

微信云开发按资源点计费，计算器写 1,000 点 = 1 元。免费云环境每月 40,000 点，可体验 6 个月，超量不能按量付。

基础套餐 19.9 元/月（原价 39 元），同样 40,000 点，可以加购、可以按量。[计算器](https://cloud.weixin.qq.com/cloudbase/price)

做微信小程序，这一格入门和进阶都写微信云开发。车主的云函数合入 `dev` 后由 `cloud-deploy` 部署到云开发环境。

普通网站的托管这次没核单价，不写。

### 模型 API、知识库、监控、沟通

这四类有用，但不是这一页的主角。

模型接口：写代码的订阅已经含模型。产品里要嵌 AI，才另接。

车主小程序的文字生成走云开发，2026-11-03 确认用 `deepseek-v4.1-flash`。台账里的 token 单价查询日是 2026-10-12，不能当成今天的现价，数字见小程序 `docs/cost-ledger.md`，这里不抄。

知识库：给 AI 研发团队的规矩放在仓库 `AGENTS.md` 和 `docs/`，不另买。给员工看的制度，飞书免费版已经含知识库，留到演讲 05「把规则书换成公司制度」再说。

监控：Actions 失败会往故障日志留一条；云开发日志用 `cloud-diag` 看。第一版不必再买一套监控。

沟通：飞书免费版含消息。企业微信帮助中心写注册免费，可选的认证费 300 元起、有效期 1 年；高级邮箱、微盘等另计。

每个企业免费 2,000 个外部联系人。[注册说明](https://open.work.weixin.qq.com/help2/pc/15422?person_id=1)、[外部联系人](https://work.weixin.qq.com/nl/act/p/e04d245b329a451a) 车主对玩家用小程序和公众号，这份对照里没看到企业微信。

## 为什么上页只留 5 类

听众是用过 AI、不做开发的老板。一屏再多，名字就记不住。

写代码的 AI、放代码、管任务，缺一个就转不起来，三行都留。

放上线现在的表没有。代码没有地方跑，做出来只停在仓库里。

做小程序就写微信云开发，一行够了。

工作流车主要加。加的是飞书表格和 GitHub Actions，不是扣子或 n8n。

飞书表已经在收反馈，单独再占一行「收反馈」会让人以为要买两个东西。Actions 是 GitHub 免费版里就有的，进阶格写它，老板不会多掏一笔。

模型接口留到 05。这一页讲的是谁来写软件，不是软件里怎么调用模型。

知识库、监控、沟通都嵌在上面几行里：规矩在仓库，告警在 Actions，说话用公司已有的飞书或微信。再各占一行，就是把后台菜单念完。

扣子、宜搭适合「先不做定制软件、用表单把流程跑起来」。那是另一场演讲，被问到就说有免费档，不放进这张表。
