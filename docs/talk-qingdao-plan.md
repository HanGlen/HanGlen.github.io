## 5. 教程：一个人零基础做微信小程序
前两步「能做出来」，后两步「做得专业」。起步（注册小程序、装开发者工具、让 AI 建项目）半页带过。

1. **选对模型**：两张榜，悬停看分。审美和前端看 LMArena WebDev 榜（伯克利起家，真人盲投）；写代码看 SWE-bench（普林斯顿，用真实开源 bug 考 AI）。讲前一周截最新榜；台上只讲怎么看榜，不推荐具体哪家，国内用户看国产模型排第几。
2. **GitHub 仓库当操作台**：仓库在中间，Claude、Codex、Trae 像插头插进来。代码、规则、任务、检查都在仓库里，AI 是来干活的，哪个好用换哪个，不被一家绑住。
3. **规则文档**：放真实的 `AGENTS.md`，悬停某行弹出「这行是因为出过什么事才加的」。AI 每次都不记得上次，规则文档就是它的员工手册。
4. **工作流**：开单 → AI 领活 → 写代码 → 183 道自动检查 → 合入 → 上线，8 个定时任务轮班；用 2.5 小时那条玩家反馈走一遍（复用 `Relay`）。这里放「我」的数字：1,633 个 PR、日均 26 个。
